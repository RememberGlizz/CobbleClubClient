CobbleClub 2.6 - Permission Nodes
=================================

LuckPerms is OPTIONAL.
- If LuckPerms is not installed, normal player nodes below default to ALLOWED.
- Admin nodes fall back to vanilla OP level 2.
- If LuckPerms is installed, an explicit TRUE/FALSE overrides the built-in default.
- Console is allowed to use admin commands.

Recommended admin grant:
/lp group admin permission set cobbleclub.admin.* true

Recommended normal-player claim access (normally already allowed by default):
/lp group default permission set cobbleclub.command.claim true
/lp group default permission set cobbleclub.claims.use true

PER-CLAIM ROLE SETTINGS
-----------------------
These are controlled inside the claim GUI and are NOT LuckPerms nodes.
Each can be VISITOR, TRUSTED, or OWNER, including subclaim overrides.

build       Place and break blocks
interact    Doors, buttons, beds, redstone and general block interaction
containers  Chests, barrels, hoppers and inventories
item_use    Buckets and protected item-use actions
entities    Attack/use mobs, armor stands, vehicles and other entities
pvp         Attack players inside the claim

CLAIM PROTECTION INCLUDED IN THIS UPDATE
----------------------------------------
- Fast chunk-indexed claim lookup instead of scanning every claim on every interaction.
- Block breaking protection.
- Block placement protection, including claim-border placement checks.
- Container protection.
- Doors/buttons/redstone/general block-use protection.
- Bucket/item-use protection for protected land.
- Entity interaction/attack protection.
- Separate PvP permission.
- Banned players are actively ejected from the claim instead of only being told they are banned.
- Subclaim permission overrides apply to the expanded permission set.
- Claim files save atomically and keep claims.json.bak as a recovery backup.
- Existing owner/trusted/visitor roles, transfer, bans, messages, teleport, resize and map GUI remain intact.

NOTE
----
This is a standalone CobbleClub claim system; Flan is not required. It intentionally does not import or depend on Flan.
