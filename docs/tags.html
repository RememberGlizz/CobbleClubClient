Player identity

Tags

CobbleClub tags are graphical badges shown through the custom tag font. Rank tags synchronize automatically, while selected achievement/premium tags can be owned and switched manually.

/tags

Open the tag menu

Use /tags or /tag. The menu separates tags you can use from tags that are locked, rank-bound or purchasable.

Shiny Hunter

Price

50,000 PokéDollars

Access

Available to normal/premium non-staff rank groups under the current access rules. Rank/staff badges themselves are not store-bought tags.

/tag buy shiny_hunter

Command form for purchasing the Shiny Hunter tag when you meet the rules and can afford it.

Automatic behavior

Switching and promotions

  • Rank promotion sync automatically checks which rank badge should be your default.
  • Tag switching has a 15-second cooldown to prevent rapid spam.
  • Premium rank promotions can broadcast the upgrade and invite players to drop a GG in chat.
