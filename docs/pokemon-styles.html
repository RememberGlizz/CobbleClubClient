Preview catalog

Pokémon Styles & gear

CobbleClub includes custom preview menus for server-specific Pokémon styles/variants and custom gear. These menus are for browsing what the server exposes without needing admin commands.

Catalog

Pokémon Styles

Open the catalog from the `/club` dashboard or use /pokemonpreview. The client supports grouped browsing such as Favorites, Regionals and Forms when those entries are advertised by the server catalog.

Preview ≠ acquisition method
A preview entry means “this is represented by the CobbleClub catalog.” It does not automatically mean every style is obtainable in the same way. Acquisition rules can differ by feature/reward and are intentionally kept server-authoritative.
Custom equipment

Gear Preview

/gearpreview

Open the custom gear preview.

Rank kits currently include themed armor sets: Spark (Ace), Spectral (Champion), Aura (Master) and Fairy (Legend). Use the kit guide for exact reward contents.

Related catalog

Crate previews

/cratepreview <crate>

Open a graphical preview of a configured crate.

The `/club` dashboard also contains direct Vote, Shiny and Legendary crate-preview actions.
