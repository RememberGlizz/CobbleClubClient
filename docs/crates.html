Keys & rewards

Crates

CobbleClub has three custom crate tiers. Their keys live in one synchronized CobbleClub wallet so menus, rewards and physical crates all read the same balances.

Vote

Vote Crate

Earn Vote Keys through valid server votes. Vote rewards include the normal PokéBlocks doll pool and other configured rewards.

Shiny

Shiny Crate

Uses Shiny Keys and can include shiny-themed rewards, including shiny PokéBlocks dolls.

Legendary

Legendary Crate

Uses Legendary Keys and targets the highest-tier/legendary reward pool, including legendary PokéBlocks dolls.

Commands

Check and preview

/keys

Show your Vote, Shiny and Legendary key counts.

/crate preview <crate>

Preview a configured crate without spending a key.

/crate open <crate>

Open a configured crate if you have its key.

/cratepreview <crate>

Open the dedicated preview screen.

At the crate area

Physical crates

Physical crate interactions are backed by the same CobbleClub key wallet. Normal interaction opens/uses the crate; sneak interaction is used for preview behavior where configured.

Vote-key rule
Vote Crates are intentionally vote-driven. The default `/daily` reward grants no Vote Key. Shiny and Legendary systems can have separate Gem purchasing rules, while the Vote crate should not be treated as a Gem-purchase crate.
Reward types

What a crate can reward

The crate engine can award configured items, PokéDollars, claim blocks, extra keys, tags, cosmetics, glows, Pokémon or server commands. The actual preview menu is the authoritative current reward list because pools can be tuned without rewriting this page.
