This page sends you to the mod authors’ own documentation or project page. Use it when the question is about a third-party mod rather than a CobbleClub custom system.

Two layers of documentation
CobbleClub-specific commands, prices, claims, shops, kits, tags and Wild Worlds are documented on this wiki. External links below are for the other mods in the pack and may describe features that the server has configured differently.

Libraries & performance

What is intentionally not listed

The modpack also contains libraries, compatibility layers, rendering/performance mods and infrastructure such as Fabric API, Architectury, Cloth Config, Sodium, Lithium, ModernFix and similar dependencies. They matter for the pack to run, but they are not gameplay systems a normal player needs a “how to play” guide for.

Troubleshooting rule
If you are troubleshooting installation or a crash, those support mods suddenly do matter. In that case, use the exact pack version and the crash log rather than randomly updating one dependency in isolation.
