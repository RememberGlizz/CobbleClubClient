What CobbleClub tracks

Progression systems

Economy

PokéDollars are the main money balance; Gems are a separate progression currency. CobbleClub pays rewards for playtime, catches, PvE wins, contracts, daily claims and valid votes.

Economy guide →

Claim capacity

Your protected land is limited by claim blocks. You begin with 700, and each paid expansion adds 256 blocks. The purchase price is in Gems and scales with every successful purchase.

How you interact with the server

Player systems

Protection

Claims & subclaims

Map-based land protection with roles, granular permissions, trust, bans, messages, transfers and safe teleporting.

Trading

Chest Shops

Claim-aware player shops that use a chest for stock and a sign/UI for secure PokéDollar sales.

Why the CobbleClub client matters

Client + server matching

Exact build required
CobbleClub's custom menus and networking require the matching client build. The server performs a build handshake so old client UI cannot silently connect to a newer server implementation.

This is why menu upgrades—such as Wild Worlds, claims, tags, wardrobe and chest-shop UI—are distributed as part of the CobbleClub client mod as well as the server component.
