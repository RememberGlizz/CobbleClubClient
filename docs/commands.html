Player Commands

Useful commands available throughout CobbleClub. Availability can depend on world, rank or server permissions.

Core

/kits

Open the CobbleClub kits menu.

/bal

View your PokéDollar balance.

/daily

Claim the server's daily reward when eligible.

/rtp

Random teleport where the server permits it.

Pokédex

/pokedexstats

Open CobbleClub Pokédex statistics.

Worlds

CobbleClub uses separate wild/resource worlds. Some teleport commands are intentionally restricted by location.

Note: This page lists confirmed CobbleClub commands and will be expanded as the public command set is finalized.
