Player Command Reference

This page is for commands intended for ordinary CobbleClub players. Staff, debugging, Pokémon-spawning and administrative commands are intentionally excluded.

Tip: Commands can be restricted by world, rank, cooldown or permissions. A command being part of a mod does not automatically mean normal players can use it.

What is not listed here?

Cobblemon itself contains many commands for administrators and testing—such as spawning, giving or editing Pokémon. Those are not normal survival-player commands on CobbleClub and are therefore not presented here as gameplay features. The official Cobblemon command reference can still be useful for understanding the base mod, but availability on CobbleClub is controlled by server permissions.

World restrictions

Teleportation is intentionally context-sensitive. For example, RTP is designed around the server's exploration worlds and may be unavailable from protected/special locations. This prevents teleport commands from bypassing the intended flow of spawn, raids or other special areas.

Ranks and permissions

Some features are unlocked by server rank. CobbleClub uses permissions behind the scenes to decide whether a player may access a command or kit. You never need operator status for ordinary gameplay.

Can't use a command?

Check spelling first, then check whether you are in a special world, whether the feature has a cooldown, and whether it belongs to a rank you have not unlocked. If the command is an admin command from a third-party mod, it may intentionally be unavailable.

Accuracy policy: Only commands confirmed for CobbleClub's player experience are documented as player commands. More will be added as their live permissions are verified.
