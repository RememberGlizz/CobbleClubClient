Quick answers

FAQ

Short answers to common “how do I…?” questions. Each answer links to the full guide when there is more to know.

How do I see all CobbleClub systems?
Run /club. It is the main dashboard for balances, claims, kits, tags, wardrobe, previews and key information. Custom Features →
How do I go to a Wild World?
Run /wild and pick one of the nine world cards. For a safe random start, use /rtp. Wild Worlds →
How do I reach the Resource World?
Use /wild and choose Resource, or run /rtp resource. The old resourceworld command is not the current CobbleClub path.
How do I protect my base?
Run /claim, select chunks on the map and confirm. New players start with 700 claim blocks. Claims →
Why can't I claim more land?
Each chunk costs 256 claim blocks. Check /claim blocks. You can buy +256 capacity with Gems; prices scale after each purchase.
How do I let a friend build but not own my claim?
Trust them and configure the claim role permissions. Build/Break, Containers, Use Blocks, Items, Entities, Chest Shops and PvP can be controlled separately.
How do I make a player shop?
Place a chest in your claim, run /chestshop, right-click a side of the chest, choose an item, set the price and stock the chest. Chest Shops →
How do I make money?
Playtime, catches, PvE wins, contracts, `/sell`, daily rewards, valid votes and player shops can all pay PokéDollars. Economy →
How do I send money to another player?
Use /pay <player> <amount>.
What are Gems for?
Gems are a separate progression balance. One major use is purchasing additional claim-block capacity.
How do I see my crate keys?
Use /keys or open `/club`. Vote, Shiny and Legendary keys share the CobbleClub key wallet.
How do I get Vote Keys?
The default vote event gives 1 Vote Key + 250 PokéDollars. `/daily` does not give a Vote Key by default. Voting →
How do I use my rank kit?
Run /kits. Your exact current rank has its own kit and cooldown. Kits →
Can I shorten my kit cooldown?
Yes. The kit UI can sell one-hour reductions for 500 PokéDollars, capped per cycle (4h standard, 6h Legend).
How do I equip cosmetics?
Use /wardrobe. You can equip categories, glow, save up to five presets and hide/show your look. Wardrobe →
How do I change my chat/name tag badge?
Use /tags. Rank badges synchronize automatically; selected tags such as Shiny Hunter can be purchased/unlocked. Tags →
How do I teleport to another player?
Use /tpa <player>. They can click Accept/Deny or type `/tpayes` / `/tpano`. Requests expire after 60 seconds.
Where do I learn another mod's mechanics?
Use Modpack References. It links the authors' official wikis/project pages for Cobblemon, Mega Showdown, raids, trainers, breeding, storage and more.
Why does a CobbleClub menu say my client is wrong?
Custom menus/networking require the matching CobbleClub client build. Install the exact version that matches the server instead of mixing old and new jars.
