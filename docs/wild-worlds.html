/rtp

Random teleport

1

Run `/rtp`

CobbleClub chooses a random colored Wild World and begins a 3-second warmup.

2

Stay still

Moving during the warmup cancels the teleport.

3

Safe location search

The server tries safe surface positions between 500 and 19,000 blocks from the world center and avoids dangerous blocks such as water, lava, magma, cactus and fire.

4

Explore

After a successful RTP, the 5-minute cooldown begins.

World safety

Borders & existing worlds

Managed worlds use a 40,000 × 40,000 world-border target centered at 0,0. RTP deliberately stays inside that boundary, using a maximum radius of 19,000 blocks.

Existing builds
CobbleClub adopts existing managed-world folders instead of casually regenerating them. That protects existing builds and terrain when worlds already exist.
Old command removed from this guide
Do not use the old `/resourceworld tp resource` instruction from older wiki versions. The current CobbleClub path is `/wild` or `/rtp resource`.
