Wild Worlds

CobbleClub separates its adventure areas into multiple custom worlds so players can explore away from the main protected server area.

Random teleport

The server's random-teleport system is configured around the wild-world experience. RTP access can be restricted depending on the world or protected area you are standing in.

Resource World

CobbleClub also has a separate resource world used for gathering resources without relying entirely on permanent build areas.
