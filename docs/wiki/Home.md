## Design Direction

CobbleClub is intended to feel like one connected server experience.

Claims, progression, rewards, economy, kits, worlds, cosmetics, crates and menus are designed to work together instead of feeling like unrelated systems layered on top of Minecraft.

The documentation follows the same idea: clean sections, direct explanations and practical examples.
