# Economy, Gems & Rewards

CobbleClub stores persistent economy/player reward data.

## PokéDollars

Used across server systems such as:

- Purchases
- Claim blocks
- Rewards
- Rank/store integrations
- Player progression

## Gems

A secondary server currency used for premium/progression systems.

## Reward Sources

Depending on server configuration, rewards can come from:

- Playtime
- Pokémon catches
- Shiny catches
- Legendary catches
- Voting
- Trainer milestones
- Kits
- Crates
- Events

## Trainer Path Rewards

Kanto first-clear rewards are persisted independently of normal battle rematches.

This prevents duplication while still allowing trainers to be battled again when RCT allows it.
