# Getting Started

## Requirements

CobbleClub currently targets:

- Minecraft 1.21.1
- Fabric
- Java 21
- Cobblemon 1.8 line
- Exact matching CobbleClub client/server build

## First Join Checklist

1. Install the exact CobbleClub build required by the server.
2. Join and open `/club`.
3. Obtain the Newb kit / claiming tool when applicable.
4. Open `/claim` and learn the claim interface.
5. Begin the current RCT trainer pathway.
6. Use the Featherboard for quick server/player information.
7. Toggle the board with `/board` if you want a clear screen.

## Kanto as the Initial RCT Path

The Kanto series id is:

```
cobbleclub_kanto
```

To make Kanto the automatic starting pathway for new/unassigned RCT players, set RCT's initial series to that id in the server configuration.

Existing players that already have RCT series/progression data may require separate migration.

## Client/Server Matching

CobbleClub uses custom packets and menus.

If the client and server do not match, the server can reject the connection with a message showing both versions.

Always install the same CobbleClub jar on both sides when the build is client+server.
