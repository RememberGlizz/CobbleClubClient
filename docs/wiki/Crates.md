# Crates

## Crate Types

- Vote
- Shiny
- Legendary

## Keys

CobbleClub crate keys are synchronized with the main mod data so the same key balance is used consistently.

Example administrative key command used by the server:

```
/cobbleclubserver give key <player> shiny 1
```

## Pokéblock Dolls

Suggested distribution:

- Normal Pokémon dolls → Vote
- Shiny Pokémon dolls → Shiny
- Legendary Pokémon dolls → Legendary

## Vote Crate

The Vote crate is intentionally vote-focused and should not expose the same Gems purchase flow used by premium crates.
