# Commands & Permissions

## Main Menu

```
/club
/cobbleclub
```

Opens the main CobbleClub interface.

Typical permission:

```
cobbleclub.command.club
```

## Kits

```
/kits
/kit
```

Typical permission:

```
cobbleclub.command.kits
```

## Claims

```
/claim
/claim menu
/claim tool
/claim blocks
```

Common permission family:

```
cobbleclub.command.claim
cobbleclub.command.claim.tool
cobbleclub.command.claim.blocks
```

## Featherboard

```
/board
```

Client-side toggle.

It only affects the local player's HUD.

## Links / Information

## Internal Commands

The RCT reward bridge is an internal implementation command.

It is protected by a pending milestone tag generated by RCT progression and is not intended as a normal player command.
