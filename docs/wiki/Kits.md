# Kits

## Kit Families

- Newb
- Ace
- Champion
- Master
- Legend

## Newb

Designed as the starting kit.

Can support:

- First-join automatic delivery
- Claiming tool
- Basic adventure items
- Recovery through the kit/claim workflow

## Premium Kits

Ace, Champion, Master and Legend are intended to be permission/rank controlled.

The UI shows access and cooldown state.

Cooldown reduction systems can be layered on top of the base cooldown configuration.
