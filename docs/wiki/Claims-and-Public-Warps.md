# Claims & Public Warps

## Overview

CobbleClub Claims provides visual land protection with map support and persistent server data.

## Core Features

- Create claims
- Resize claims
- Rename claims
- Delete claims
- Transfer ownership
- Trust players
- Ban players
- Configure permissions
- Create sub-claims
- Configure enter/leave messaging
- View claim borders
- Teleport to claims
- Manage claim-block budgets
- Publish public claim warps

## Claim Map

The map displays claim locations and supports visual selection.

Map controls are hidden while a claim detail overlay is open so controls do not bleed through the panel.

## Claim Blocks

Players have a claim-block budget.

The header shows remaining/used blocks when space allows. On compact layouts, the value is hidden instead of overlapping navigation tabs.

## Trusted Claims

Trusted players can receive claim access without becoming the owner.

Leaving a trusted claim only removes that player's trusted membership.

## Public Warps

Owners can:

- Set a public warp name
- Enable public access
- Disable public access

Public visitors stay Visitors.

They do not become trusted members and do not gain build/edit/manage permissions.

Chest-shop purchasing can remain available when claim rules permit it.

## Public Warps Tab

The global list can show:

- Warp name
- Claim name
- Owner
- World

## UI Safety

Teleport, Map, Delete and Leave controls are constrained to the claim-detail panel.

Scrollable content stays clipped to the panel rather than drawing outside its border.
