How rewards arrive

1

Vote using your correct Minecraft username

The external site sends the vote event toward the server's voting bridge.

2

CobbleClub receives the event

When the event reaches the server, CobbleClub applies the configured vote reward.

3

If you are online

The reward is delivered immediately.

4

If you are offline

Supported pending votes are queued and paid when you next join.

Default configuration
The default reward is 250 PokéDollars + 1 Vote Key. Server owners can tune vote settings, so the live server message should be treated as authoritative if values are changed later.
