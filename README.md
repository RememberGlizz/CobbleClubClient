**CobbleClub V3.8 – Store Integration & Stability Update**

This release updates CobbleClub's unified client/server mod with the latest server systems and compatibility changes required for the CobbleClub network.

**Changes:**

Added CobbleClub Store integration for automatic purchase fulfillment
Added secure server-to-store bridge support
Added automatic delivery support for ranks, Gems, crate keys, and cosmetics
Added persistent/idempotent purchase fulfillment protection
Updated server config to Config Version 18
Replaced Pikachu Floaty with the new Squirtle Floaty
Improved Lucario mask positioning
Fixed claim border movement/flickering
Includes the latest unified client + server networking and stability fixes

**Required Update:
All CobbleClub players must update to this version to remain compatible with the server.**

Minecraft: 1.21.1
Fabric
Cobblemon: 1.7.3

**This release must be installed alongside the latest CobbleClub Modrinth modpack version before connecting to the server.**
